# MUAP interactive presentation

`MUAP_Hazir_Sunum.html` is the latest self-contained Turkish teaching deck for motor-unit action potential (MUAP) analysis.

## Open

Open the HTML file in a current desktop browser. Use the on-screen controls or keyboard arrows to move through the progressive steps. The file does not require a server, package installation, network connection, or patient dataset.

## Scope

- 121 audience-facing slides with progressive reveals
- motor-unit foundations and MUAP formation
- recording position, duration, amplitude, phases, and polyphasia
- sampling, reference context, firing behavior, and recruitment
- integrated interpretation with explicit limits

All displayed traces and diagrams are authored teaching schematics. They are intentionally labeled as non-patient data and should not be used for diagnosis, clinical reporting, or patient-specific decisions.

## Sources

Source labels are retained within the presentation, including citations to Preston & Shapiro (2020) and selected external educational resources. The cited publications and linked resources are not bundled with this repository. See the repository `NOTICE` file.
