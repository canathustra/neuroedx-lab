# 30-day roadmap

## Week 1 — clean foundation

- Publish the independent public repository.
- Add Apache-2.0 license, contribution rules, data policy, and clinical governance.
- Ship the median motor / APB simulator with deterministic synthetic signals.
- Test velocity calculation, recruitment plateau, and waveform determinism.

## Week 2 — teaching quality

- Add guided marker-placement practice and technique-specific feedback.
- Add limb-temperature and electrode-placement pitfalls.
- Recruit one independent electrodiagnostic clinician for content review.
- Add Turkish/English terminology mapping.

## Week 3 — broader protocol coverage

- Add ulnar motor / ADM protocol using the same synthetic-only architecture.
- Add a technical-artifact scenario and comparison exercise.
- Document a scenario-authoring schema for contributors.
- Add accessibility and keyboard-use checks.

## Week 4 — reviewable v0.1

- Resolve clinical review findings.
- Publish a tagged v0.1 release and public project board.
- Add a short contributor demo and architecture note.
- Begin recruiting educators and clinical reviewers.

## Not in v0.1

- Patient uploads or stored clinical records
- Automated diagnosis or report generation
- Device integration
- Universal normative cutoffs
- Training or benchmarking on human-derived signals
