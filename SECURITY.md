# Security and sensitive-data reporting

Do not open a public issue for a security vulnerability, accidental patient-data submission, credential, or private record. Contact the maintainer privately through the email address on the maintainer's GitHub profile and include only the minimum information needed to locate the problem. Do not attach or repeat sensitive content.

Response goals:

- acknowledge a report within 72 hours;
- restrict access to exposed sensitive content as soon as practical;
- assess affected versions and users;
- publish a minimal, non-sensitive advisory when users must act.

This project accepts no patient data. Any patient-related content is treated as an incident, not a valid fixture or contribution.
